# Редактирование чертежа

Команды можно вызвать из меню **Правка** или ввести в консоли. Имя с `_` работает на любом языке, русское имя — в русском интерфейсе. Текущий запрос виден и в строке ввода, и под холстом. Точки задаются как `x,y`, десятичный знак — точка. Каждый ответ в примерах заканчивается **Enter**.

Размеры (`_DIM…`), штриховки, блоки и виды на листе описаны в [руководстве по выпуску чертежа](../docs/DRAWINGS.md). Там же есть готовый пример А4, 1:2.

## Выбор и подтверждение

* **Сначала объекты:** выделите штрихи щелчком или рамкой и запустите команду. Команда сразу перейдёт к следующему запросу. Для добавления к предварительному выбору удерживайте Ctrl, для исключения — Shift.
* **Сначала команда:** при пустом выборе запустите команду, укажите объекты щелчками или рамкой и нажмите Enter. Щелчки на этом этапе накапливают выбор. Вместо мыши можно ввести набор ID одной строкой, например `#2 #5`; это сразу подтверждает набор.
* Когда команда просит **точку**, можно чередовать мышь и консоль. Для подтверждения видимого предпросмотра — щелчок или Enter при курсоре в холсте. Когда важны **и объект, и место на нём**, например участок для обрезки, ответ имеет вид `#ID x,y`.
* **Esc во время правки** убирает предпросмотр, но не отменяет предыдущую команду, не стирает выбор и не меняет ветку повтора. Вне команды Esc снимает выбор. Успешное действие, в том числе над несколькими объектами, отменяется одним `_UNDO` и возвращается одним `_REDO`.

## Преобразования

| Команда | Что указать после выбора | Результат |
|---|---|---|
| `_MOVE` / `ПЕРЕНЕСТИ` | Базовая и конечная точки | Перенос на разность точек; ID остаются прежними. |
| `_COPY` / `КОПИРОВАТЬ` | Базовая и конечная точки | Копии с новыми ID; исходные объекты остаются. |
| `_ROTATE` / `ПОВЕРНУТЬ` | Центр, затем угол в **градусах** или точка направления | Ноль — вдоль +X, положительный поворот — против часовой стрелки. |
| `_SCALE` / `МАСШТАБ` | База, затем коэффициент (`2` = вдвое) или точка нового размера | При указании точки коэффициент равен расстоянию от базы, делённому на исходную длину из подсказки. |
| `_MIRROR` / `ЗЕРКАЛО` | Две разные точки оси | Отражает выбранные объекты **на месте**; у дуг и bulge меняет направление, у текста отражает и размещение, и глифы. |
| `_ERASE` / `СТЕРЕТЬ` | Выбор | Удаление группы. В холсте тот же путь вызывает **Delete**. |

В `_SCALE` исходная длина по умолчанию — расстояние от базы до самого дальнего угла среди AABB выбранных объектов. Чтобы увеличить известный размер 10 до 25, задайте базу `0,0`, ответьте `R`, `10`, затем **точкой** `25,0`. Числовой ответ на запрос коэффициента всегда означает множитель. Для разных масштабов по осям есть ввод `XY sx sy`; окружность, дуга или bulge-сегмент в наборе требуют равных модулей масштабов. Например, `XY 2 3` для окружности даёт отказ, **не** эллипс и не частичное масштабирование остальных объектов.

## Обрезка, удлинение, смещение и сопряжение

| Команда | Порядок действий |
|---|---|
| `_TRIM` / `ОБРЕЗАТЬ` | Выберите одну или несколько **режущих** сущностей, затем укажите часть **другой** сущности для удаления. Считаются пересечения конечных отрезков и круговых рёбер, включая дуги полилиний. Средний интервал открытого пути может оставить два объекта. Для окружности нужны хотя бы два различных пересечения: остаётся дуга. |
| `_EXTEND` / `УДЛИНИТЬ` | Выберите **границы**, затем щёлкните ближе к удлиняемому концу отрезка или дуги. Берётся первое пересечение вперёд **на самой границе**; если пересекается лишь её воображаемое продолжение, команда не меняет объект. |
| `_OFFSET` / `СМЕСТИТЬ` | Выберите **один** отрезок, окружность, дугу или полилинию, введите положительное расстояние и укажите точку со стороны новой кривой. Положение щелчка задаёт **сторону**, не расстояние. Создаётся копия. Внутреннее смещение с `r − d ≤ EPSILON` отклоняется. |
| `_FILLET` / `СОПРЯЖЕНИЕ` | Выберите один или два отрезка, введите радиус, затем укажите на каждом отрезке **сохраняемую сторону**. При `R = 0` концы сходятся в углу без дуги; при `R > 0` появляются два касания и круговая дуга. Параллельные отрезки или радиус, для которого не хватает длины, дают отказ. |

## Построение, массивы и измерения

| Команда | Порядок действий |
|---|---|
| `_RECTANG` / `ПРЯМОУГ` | Два противоположных угла или `D ширина высота` после первого угла. Создаётся **замкнутая** полилиния; `_UNDO` убирает её целиком. |
| `_POLYGON` / `МН-УГОЛ` | Число сторон 3…1024, центр, затем точка. `C` (или `О`) переключает вписанный/описанный; для описанного указанная точка — середина ребра. |
| `_CIRCLE`, `_ARC`, `_PLINE` / `КРУГ`, `ДУГА`, `ПОЛИЛИНИЯ` | Радиус или точка для окружности, три точки дуги, вершины полилинии. `C` замыкает, `Enter` завершает открытую. |
| `_LINE` / `ОТРЕЗОК` | Первая точка, затем следующая за следующей: команда продолжает строить отрезки, как в AutoCAD, пока не нажать Enter. `C` (или `З`) замыкает цепочку на первую точку, `U` (или `ОТМ`) убирает последний отрезок. Все точки можно задать и одной строкой, с `@10,0` и `10<30`. |
| `_CHAMFER` / `ФАСКА` | Выберите две линии, введите `d1` или `d1,d2`, затем укажите сохраняемые стороны. Фаска строится одной транзакцией. |
| `_ARRAY` / `МАССИВ` | `R строки столбцы dx dy` для прямоугольного массива или `P X,Y количество [угол]` для кругового. Полный оборот не дублирует элемент на 360°. Одна отмена. |
| `_MATCHPROP` / `КОПИРОВАТЬСВ` | Выберите целевые объекты, укажите исходный: копируются слой, цвет и вес линии. |
| `_DIST` / `ДИСТ`, `_AREA` / `ПЛОЩАДЬ` | Две точки либо `#ID` объекта; ответ (`Distance … mm, angle …°`, `Area … mm²`) печатается в командной строке. |

Пробел работает как **Enter**: подтверждает шаг, а на пустой строке повторяет последнюю команду. Пока команда ждёт свободный текст (имя блока, листа, стиля), пробел остаётся обычным символом. Двойной щелчок средней кнопкой показывает границы чертежа, правая кнопка открывает меню с повтором, недавними командами, свойствами, стиранием и буфером (`Ctrl+C/X/V`, `Ctrl+Shift+C` — копирование с базовой точкой). **F12** включает динамический ввод: рядом с перекрестием показаны поля длины и угла, Tab переключает поле, Enter фиксирует точку.

**Пример для пустого чертежа** (F8/F10 выключены). Результат — два отрезка `[-10,0] → [0,0]` и `[6,0] → [10,0]`; обе вертикальные кромки сохраняются. `_UNDO` восстанавливает целый горизонтальный отрезок.

```text
_LINE -10,0 10,0
_LINE 0,-4 0,4
_LINE 6,-4 6,4
_TRIM
#2 #3
#1 2,0
```

У смещённой полилинии обрабатывается и стык последнего ребра с первым. Смежные рёбра стыкуются на пересечении опорных прямых/окружностей; для внешнего угла без такого пересечения возможна круговая вставка. Реализован **один простой путь**, а не разбиение самопересечений на несколько контуров. Вырождение ребра, недопустимый стык или самопересечение результата отклоняются. Текст и блоки не являются режущими кромками. Заблокированные слои можно использовать как границу, но не редактировать.

## Точный ввод и ручки

**F8 (Орто)** оставляет только горизонталь или вертикаль от базы. **F10** включает полярное отслеживание вместо Орто. В меню **Настройки** задайте шаг 15°, 30° или 45° (изначально 30°): в пределах 5° от луча точка проецируется на него и появляется штриховая направляющая; между лучами курсор свободен. Для ввода мышью сначала ищется объектная привязка, затем применяется ограничение относительно базы. Маркер привязки скрывается, если итоговая точка с ней не совпала. Введённые координаты также учитывают активное ограничение; введённый числом угол поворота задаётся точно.

Выделите объект и щёлкните по **синей ручке**: появится красный квадрат. Передвигайте его, затем щёлкните ещё раз или нажмите Enter. Можно также зажать ручку, потянуть и отпустить. Горячий объект исключён из OSNAP, так что не «ловит» сам себя. На экране остаётся исходный штрих и появляется полупрозрачная будущая геометрия. **Esc** убирает её без записи в документ; подтверждение — **одна** транзакция.

* Отрезок: конец растягивается; середина переносит весь отрезок.
* Окружность: центр переносит её; квадрант задаёт новый радиус расстоянием до центра.
* Дуга: изменение конца или середины перестраивает дугу по трём точкам; центр переносит её целиком.
* Полилиния: ручка вершины меняет её положение с сохранением bulge. Середина прямого участка двигает оба его конца, середина дугового участка меняет прогиб при неподвижных концах.
