# Происхождение кода и условия поставки

## Что лицензируется

* Оригинальные `core`, `render`, `ui`, `io` (включая исходные штрихи шрифта PDF), приватный `sdk/host`, менеджер плагинов, интерпретатор `scripting`, тесты, документация, переводы и файлы сборки PlaneDraft предоставляются на условиях **GNU LGPL версии 2.1 или любой более поздней версии, по выбору получателя**. Полный текст версии 2.1 — [LICENSE](../LICENSE).
* Исключение с более свободными условиями: `sdk/include/`, `plugins/sample/` и `examples/` — [MIT](../LICENSES/MIT.txt). Плагин может быть коммерческим, закрытым или открытым: для этого интерфейса ему не нужно компилировать исходники ядра, наследовать C++-классы хоста или даже линковаться с Qt. MIT-уведомление сохраняется. SDK не перелицензирует чужие зависимости плагина.
* Не включены сторонний CAD-код, дампы DWG, бинарные SDK, коммерческие шрифты/SHX, чужие `.pat`/`.lin` и чертежи. Для UI используются шрифты установленной системы, их файлы не копируются. MSVC, Windows SDK и драйвер — инструменты/системные компоненты целевой ОС, не исходники приложения.

В видовом экране контуры `Text` строятся во время работы средствами Qt из системного шрифта. Файлы чужих шрифтов не копируются. PDF-шрифт описан собственными штрихами. [Пример крышки панели](../examples/drawings/cover.dxf) — оригинальный тестовый рисунок из аналитических примитивов PlaneDraft, распространяется как пример по MIT; импортированных чертежей или символов сторонних САПР в нём нет. [Панель с сечением и листом А4](../examples/drawings/panel.dxf) также создана для PlaneDraft и предоставляется по MIT. Размерная графика, узоры и геометрия основной надписи построены программно, без сторонних библиотек шаблонов.

Полный реестр, в том числе Qt SVG, его встроенный XSVG, Qt Translations, тестовые читатели и инструменты упаковки, — в [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md). В Windows-пакете `RUNTIME_INVENTORY.md` связывает каждый бинарный файл и каталог переводов с источником и контрольной суммой; `LICENSES/ports/` содержит данные только фактических владельцев файлов.

## Реестр прямых зависимостей

| Компонент | Где используется | Условия, выбранные для открытой сборки |
|---|---|---|
| [Qt Base](https://github.com/qt/qtbase/tree/v6.9.3), 6.9.3 в Windows baseline | Qt6 Core/Gui/Widgets/OpenGL/OpenGLWidgets, развёрнутая Qt6Network, платформенный backend | Открытый вариант **LGPL-3.0** для соответствующих библиотек. Динамический triplet, сменяемые DLL. Это не Qt под LGPL-2.1. Для комбинации собственный код `-or-later` допускает выбор LGPLv3. |
| [Qt SVG](https://github.com/qt/qtsvg/tree/v6.9.3), 6.9.3 | SVG-значки инструментов | LGPL-3.0-only для библиотеки, отдельное уведомление XSVG. Сами значки — собственные. |
| [Qt Translations](https://github.com/qt/qttranslations/tree/v6.9.3), 6.9.3 | `qtbase_ru.qm` для стандартных диалогов | Правила лицензирования модуля и уведомления конкретного порта; не копируем другие языки или переводы программ Qt. |
| [Qt Tools](https://github.com/qt/qttools/tree/v6.9.3), 6.9.3 | `lupdate`, `lrelease` в процессе сборки, не в exe | Для инструментов Linguist — GPLv3 с Qt GPL exception согласно заголовкам upstream; распространять нужно свой каталог переводов, не исполняемые файлы инструментов. Метаданные vcpkg не заменяют проверку конкретных файлов. |
| [GoogleTest](https://github.com/google/googletest/tree/v1.17.0), 1.17.0 | Только тестовые цели | BSD-3-Clause; не линкуется в PlaneDraft или sample DLL. |
| STL C++20, системный OpenGL API | Ядро и рендерер | Нет вендоринга реализации STL или драйвера; отдельно проверять состав runtime при упаковке под Windows. |

Точные рецепты портов закреплены в `vcpkg.json`. **Список прямых зависимостей не является SBOM бинарника.** Даже у открытого Qt есть встроенные и транзитивные компоненты с собственными уведомлениями (например, zlib и libpng из графа портов). Их лицензии открыты, но не тождественны MIT/BSD/Apache/LGPL/GPL. Если перечень разрешённых лицензий понимать буквально и применять ко *всем* транзитивным компонентам, обычная сборка Qt/vcpkg сама по себе этому условию не удовлетворяет. До замены компонента/стека или явного согласования расширенного перечня **не публикуем бинарный дистрибутив**. Обычный push не публикует релиз; явная подготовка черновика не снимает этот рубеж.

## Сверка Windows x64 для v0.1.0

[Задание MSVC с проверкой ZIP и установленного комплекта](https://github.com/Alchimon-Code/FreeCAD/actions/runs/44516861855/job/135535007043) проверило **25** исполняемых файлов и каталогов: 4 файла PlaneDraft (два EXE и два примера DLL), 8 DLL Microsoft CRT, 7 библиотек Qt (включая `Qt6Network.dll` и `Qt6Svg.dll`), `qwindows.dll`, `qtbase_ru.qm` и 4 транзитивные DLL (`double-conversion`, `libpng16`, `pcre2-16`, `zlib1`). Генерируемый при установке `unins000.exe` — отдельный файл Inno Setup; его не выдаём за файл переносимого ZIP. GTest, Linguist и LibreDWG в реестре отсутствуют.

Для семи фактических портов сверены SHA-256 файлов `share/<port>/copyright` из комплекта: для `qtbase`, `qtsvg`, `qttranslations` воспроизведено объединение upstream `LICENSES/` версии 6.9.3 по закреплённому рецепту; для остальных четырёх совпадают файлы указанных upstream-ревизий. `LicenseRef-vcpkg-null` у Qt и `NOASSERTION` у double-conversion не являются лицензиями. У PCRE2 10.47 порт копирует лишь 97-байтовую отсылку `COPYING`, поэтому дополнительно поставляются и проверяются [полный текст PCRE2](../LICENSES/PCRE2-10.47.txt) и [уведомление SLJIT](../LICENSES/SLJIT-45f910b.txt). Замена DLL Qt, исходники и патчи закреплённых портов доступны независимо от примеров SDK. Сверка состава не заменяет согласования условий публичной поставки, в частности Zlib, libpng-2.0 и условий MSVC/Inno Setup.

## Рубеж перед включением зависимости или выпуском бинарника

1. Зафиксировать исходный upstream, тег/коммит и хеш, проверить SPDX и тексты лицензий для исходников, ресурсов и вложенных third-party. Рассматривать runtime, инструменты и тесты раздельно. Указать, что реально попадает в поставку, а не только что было собрано в `vcpkg_installed`.
2. Сформировать перечень файлов и SBOM фактического пакета; сверить его с `share/<port>/copyright` и `vcpkg.spdx.json`, Qt attributions и принятыми лицензиями. Не копировать весь каталог Qt/плагинов, инструменты разработки или проприетарные SDK в архив релиза.
3. Для распространяемых LGPL-компонентов приложить применимые тексты LGPL/GPL, notices, указание модификаций, обеспечить соответствующий исходный код установленным лицензией способом, возможность замены/перелинковки библиотек и требуемую информацию об установке. Не запрещать отладку модификаций LGPL-библиотеки. Динамическая линковка облегчает выполнение требований, но сама их не исполняет.
4. Лицензия на исходники **не гарантирует** отсутствия патентных притязаний или прав третьих лиц на конкретные данные/методы. Происхождение спецификаций, патенты в юрисдикциях поставки и право на распространение эталонных данных проверять отдельно перед релизом. Не обещать «нулевой патентный риск» по одному SPDX.

## Опциональные модули — не часть поставки

* В `pd_io` DXF написан самостоятельно по документированной структуре групп [DXF Reference (публичная документация Autodesk)](https://help.autodesk.com/view/OARX/2024/ENU/); текст спецификации и код SDK не копируются. SVG и PDF генерируются из собственной модели; Type 3 использует собственные штрихи, а не извлечённый шрифт. Для испытаний создаются свои чертежи. Нет нативного парсера DWG, исследования закрытых бинарников или чужих CAD-ресурсов.
* **DWG:** `PD_ENABLE_LIBREDWG=ON` включает только наш LGPL-клиент внешних исполняемых файлов `dwg2dxf`/`dxf2dwg`. [LibreDWG](https://github.com/LibreDWG/libredwg) — GPL-3.0-or-later. Ни код, ни заголовки, ни статическая/динамическая библиотека LibreDWG в хост, SDK или `pdconvert` не входят. Вызов — отдельный процесс с CLI и обменным ASCII DXF. При `OFF` не выполняется даже поиск инструментов. [Точный контракт, параметры и ограничения](../io/README.md).
* Пользователь отдельно выбирает и устанавливает конвертер. Флаг сборки **не** означает одобрения его происхождения или разрешения поставлять его внутри коммерческого пакета. Граница процесса сама по себе не отменяет GPL-обязательств. Перед любым комплектованием — проверка применимых условий, происхождения реализации/спецификаций, уведомления, соответствующие исходники и SBOM. По умолчанию DWG-конвертеры не распространяются. libdxfrw также не используется. Отдельные программы для проверки совместимости файлов не являются зависимостями приложения.
* Clipper2 (BSL-1.0), современные Eigen (MPL-2.0 для основной части), SQLite (public domain) и CPython (PSF и др.) — примеры, где «open source» не равно буквальному попаданию в заданный перечень. Не включать молча. На первом этапе — собственная геометрия, на следующем — документированный JSON. Вместо дополнительного интерпретатора используется собственный PlaneDraft Lisp на C++20 без внешних зависимостей; для OpenCascade отдельно проверить LGPL и исключения конкретной версии.
